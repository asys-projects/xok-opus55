Hello from Xok/ExOS

This page is served by httpd, an event-driven web server running as an ordinary unprivileged process on the Xok exokernel.

  • The file comes from C-FFS, a library file system whose on-disk structures are protected by XN through untrusted deterministic functions.
  • The TCP/IP stack is a library linked in the server; packets reach it through a dynamic packet filter and a packet ring in its own memory.

See /status for what the exokernel exposes.
